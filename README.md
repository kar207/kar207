```text

      ↓
Product Discovery
      ↓
Search • Filters • Sorting
      ↓

Returns • Saved Addresses
      ↓
Payments • Profile Security
```

## 🧠 How I Think About Frontend Engineering

<table>
<tr>
<td width="33%" align="center" valign="top">

### 01 — Product Thinking

Build around the **user journey**, not isolated screens.

<sub>Interfaces should support clear actions, reduce friction, and guide the user forward.</sub>

</td>
<td width="33%" align="center" valign="top">

### 02 — System Thinking

Create **reusable, predictable, scalable behavior**.

<sub>Components, interactions, and state should remain maintainable as the product grows.</sub>

</td>
<td width="33%" align="center" valign="top">

### 03 — Quality Thinking

Polish the **real experience**, including edge cases.

<sub>Validation, responsiveness, accessibility, feedback states, and errors matter as much as the happy path.</sub>

</td>
</tr>
</table>
